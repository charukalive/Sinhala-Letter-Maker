# Sinhala Font & Letter Studio (4u-Bindumathi • FM • Isi • Native .DOCX)

A modern, fast, 100% offline-ready Progressive Web App (PWA) designed to format official Sinhala letters with mixed English text, convert between Unicode, 4u fonts (**4u-Bindumathi**), FM fonts (**FM-Malithi**, **FM-Abhaya**), and Isi fonts (**IsiAbhaya**), and export native **.DOCX** files with dual-font styling for Microsoft Word.

---

## 🚀 Quick Start & Live Link

* 🌐 **Live Web App**: [https://charukalive.github.io/Sinhala-Letter-Formatter/](https://charukalive.github.io/Sinhala-Letter-Formatter/)
* 💻 **Local File**: Open `index.html` in any browser.

---

## ✨ Font Hierarchy & Defaults

1. **Default Selected Font**: **`4u-Bindumathi`** (Pre-selected by default).
2. **Next Supported Fonts**:
   - **`FM-Malithi`**
   - **`FM-Abhaya`**
   - **`IsiAbhaya`**
   - **`DL-Manel`**
   - **`Iskoola Potha (Unicode)`**

*(4u-Bindumathi and FM fonts share the same classic ASCII Unicode conversion mapping).*

---

## 🛡️ Dual-Font English Preservation & Native .DOCX

* When drafting official letters with embedded English words (e.g. `LF-6345`, `TATA ACE`, `AWC`, `DMT`, `CCTV`):
  * Sinhala runs are formatted in the selected font (**4u-Bindumathi** / **FM-Malithi** / **IsiAbhaya**).
  * English runs are formatted in **Arial** (completely crisp, clean, and unblurred).
  * When opening the exported **`.docx`** file in Microsoft Word, Word automatically applies the selected font to Sinhala and Arial to English.
